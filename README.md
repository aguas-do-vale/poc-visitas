# Águas do Vale · PoC de priorização de visitas

Repositório do curso *Forward Deployed Engineer: da descoberta à entrega de valor*, construído aula a aula (um commit por aula).

**Caso:** companhia de saneamento fictícia com cerca de 500 mil ligações. Pedido do cliente: "reduzir perdas".

**Tese do curso:** um pedido vago só vira projeto quando o FDE formula o problema que ele mesmo vai ter que construir. O ponto de chegada é uma PoC com IA que outro time consegue assumir.

## Aula 1 · O papel do FDE e a tese do curso

- O FDE é o engenheiro que faz o produto funcionar dentro do cliente: valor imediato para o cliente e aprendizado de volta para o produto.
- Nem todo problema precisa de um FDE: existe uma sequência de quatro filtros para aceitar ou recusar um pedido.
- "Reduzir perdas" é verdadeiro e inconstruível. Um problema bem formulado responde quatro perguntas: **decisão, restrição, sinal e onde está o dado**.
- Método do curso: hipótese, entrevistas, teste barato, teste caro, handoff.
